ETK AI Command Matrix:
Dynamic Blog Engine & Link-Map Architecture.

Standardized meta-prompting blueprint for autonomous AI generation, rigid silo link-mapping, and zero-error structural deployment across multi-file web ecosystems.

1. Master Command Blueprint (The Initial Prompt)

Mesin blog dinamis ini dikendalikan oleh satu perintah master awal (*Initial Command Matrix*). Dengan menyematkan aturan struktur silo, basis file berurutan (`file_XX.html`), dan validasi tautan balik otomatis, AI dapat memetakan ribuan halaman tanpa mengalami putus rantai referensi (*broken link maps*).

Universal Prompt Template (Salin dan Gunakan untuk Topik Lain):

"Bertindaklah sebagai Senior Web Engineer & Technical SEO Director. Kita akan membangun ekosistem blog dinamis berseri dengan format file berurutan (misal: file_91.html, file_92.html, dst.). Setiap file harus memuat: (1) Header Tailwind CSS lengkap dengan GA4 & Meta Pixel, (2) Struktur silo navigation ke index utama dan file sebelumnya/sesudahnya, (3) Schema.org TechArticle, (4) Internal linking yang akurat tanpa broken link. Jawab setiap perintah 'next' dengan menghasilkan script HTML lengkap siap salin sesuai topik utama yang kita tentukan."

2. Algoritma Akurasi Link-Map & Silo Architecture

Keunggulan dari mesin ini terletak pada konsistensi navigasi hierarkis. Sistem secara otomatis memperbarui indeks utama (`index.html`) setiap kali kelompok file baru diselesaikan, memastikan *crawl budget* mesin pencari terserap secara optimal.

Step A: Sequence Lock

Penomoran file konsisten (contoh: 81-85, 91-95) mencegah duplikasi URL dan menjaga hierarki direktori GitHub Pages / Hosting.

Step B: Cross-Silo Hook

Setiap artikel secara otomatis menyematkan tautan silang ke artikel relevan sebelumnya dan ke hub utama (`index.html#articles`).

Step C: One-Word Trigger

Cukup ketik "next" untuk memicu AI menulis artikel berikutnya secara utuh tanpa perlu merumuskan ulang instruksi teknis dari awal.

3. Cara Memulai Topik Baru (Penerapan Instan)

Jika Anda ingin beralih ke topik atau proyek lain di masa depan (misalnya e-commerce optimization, AI automation workflows, atau real estate web apps), Anda cukup memberikan format perintah awal berikut kepada bot:

Contoh Inisiasi Topik Baru:

"Mulai hari ini kita buat seri baru tentang [Masukkan Topik Anda, misal: AI Automation Workflow]. Gunakan basis file_91.html hingga file_95.html dengan struktur Command Matrix yang sama seperti proyek ETKFreelancer."
